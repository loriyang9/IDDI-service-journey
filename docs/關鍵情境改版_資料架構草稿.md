## 三、四個關鍵情境與服務流程的源起關係

以下是目前 Google Sheet 已確認的關聯。建議總覽呈現的是「關鍵情境源自哪些服務流程需求」，不是把產品生命週期誤當成服務場景關聯。

### K01 寵物家庭的避難與安置：避難所、車宿或帳棚

- 階段：備災期
- 時間：災前
- 核心場景：C01 日常生活｜物資儲備空間收納
- 族群需求：
  - 中小型犬：寵物防災包需與日常居家家具整合，內容物需精簡以利現場操作。
  - 貓：多貓家庭在日常儲備與緊急移動上面臨極高難度，需有就地備災指引。
  - 特寵：特寵日常需儲備專屬飼料，且避難時需嚴格控制環境溫濕度。

### K02 高齡者舒適與安全的睡眠環境

- 階段：緊急應變期
- 時間：0–3 天（72 小時）
- 核心場景：C04 休息與隱私｜舒適睡眠與彈性屏障
- 族群需求：
  - 高齡者：長者起臥需配備具輔助起身結構的床鋪。

### K03 不同族群安全與舒適的如廁工具

- 階段：緊急應變期
- 時間：0–3 天（72 小時）
- 核心場景：C05 衛生及如廁｜應急衛廁與環境維護
- 族群需求：
  - 高齡者：長者乃至於行動不便者需有無障礙衛廁。
  - 多元文化者：禮拜前小淨與如廁後淨下需用水清洗，衛廁需配備防水易潔設計。
  - 親子家庭：嬰幼兒家庭在避難現場，衛廁空間需配備更換尿布與清潔的工具。

### K04 災時海量物資的敏捷分類與配給系統

- 階段：緊急應變期
- 時間：0–3 天（72 小時）
- 核心場景：C03 飲食與物資｜多元儲備與配給發放
- 族群需求：
  - 高齡者：長者物資儲備應納入流質食品、假牙清潔劑及藥物等特殊需求。
  - 多元文化者：避難物資應標示清真或純素，防範災民因食材混雜而不敢進食。
  - 親子家庭：孕產婦與嬰幼兒飲食多樣且敏感，需要能快速募集到合適的餐食。
  - 寵物家庭：物資需涵蓋不同物種的飼料、醫療藥品與照護用品，並依物種分類與標示。

## 四、總覽與生命週期的分工

### 關鍵情境總覽

呈現「源起關係」：階段、時間、核心場景、族群需求。每個情境目前有一個主要核心場景，色塊可涵蓋同場景內的多個族群需求格。

### 個別情境詳情

呈現「產品全生命週期」：備災期、緊急應變期、緊急避難期、中長期收容與復原期。四個產品都會經歷完整流程，因此不應在總覽中畫成四條完全相同的滿版跨階段色帶。

## 五、現場與案例的新版分類

「現場與案例」不再依附單一設計挑戰，改以關鍵情境為主要歸屬，並使用以下類型：

- 現場觀察：訪查、演練及使用現場
- 實際災害：真實災害中的服務或避難案例
- 產品參考：既有產品與市場案例
- 構造／技術參考：結構、材料或操作方式的啟發

建議追加欄位：

1. 新版案例類型
2. 新版顯示順序
3. 新版一句觀察
4. 新版使用狀態

原有「對應設計挑戰」與「與設計挑戰的關聯」先保留作為內部追溯資料，但新版網站不顯示，也不以它們作為篩選條件。

## 六、四個產品方向

- K01：居家家具與避難兩用防災箱
- K02：高齡者安睡設計：高度、收納與隱蔽
- K03：高齡者與不便者也能穩定使用的便座
- K04：能夠快速辨識內容物，並且可轉換為收納功能的物流箱

四張「設計方向示意」需嚴格依照新版報告核心功能製作，不加入報告未提出的功能。

## 七、目前需要使用者確認的判斷

1. 總覽是否採用本稿的「源起關係」，而不是將四個產品的完整生命週期畫成服務場景關聯。
2. K01 在總覽中目前只對應 C01；後續避難安置屬於產品生命週期，而非既有試算表的來源場景。是否維持此資料定義。
3. K03 的情境問題涵蓋高齡者、多元文化者與親子家庭，但產品方向聚焦「高齡者與不便者也能穩定使用的便座」。網站將忠實呈現這項差異，不自行擴寫其他產品功能。
4. 案例改為情境層級的「現場觀察與案例啟發」，不再宣稱與個別設計挑戰一對一對應。
